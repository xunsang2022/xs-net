# XS-NET

XS-NET is a Java game-server framework and example workspace built around Apache Pekko Typed/Cluster, RPC message contracts, Protobuf, and generated client SDKs.

[简体中文](README.md) · [Architecture](ARCHITECTURE.md) · [OpenWiki](openwiki/index.md) · [SDK generation](openwiki/integrations/sdk-generation.md) · [Contributing](CONTRIBUTING.md) · [Changelog](CHANGELOG.md) · [Security](SECURITY.md) · [Third-party licenses](THIRD_PARTY_NOTICES.md)

## Repository layout

The repository contains two Maven reactors:

| Directory | Contents |
| --- | --- |
| `xs-net/` | Reusable framework modules: actor and cluster helpers, message contracts, transport abstractions, an RPC Maven plugin, SDK templates, and utilities |
| `game-server/` | An example game server with Gateway, Login, Logic, and protocol definitions |

Gateway provides Netty TCP/UDP/WebSocket access, while Logic uses Pekko Cluster Sharding. The example also integrates Redis, PostgreSQL, JWT, metrics, and client SDK generation.

## Requirements

- JDK 21
- Maven 3.9.x (or the Maven Wrapper included in the repository)
- Docker Compose (only needed for the local Redis/PostgreSQL example)

## Build

From the repository root, build all modules:

```shell
bash ./mvnw clean verify
```

On Windows PowerShell:

```powershell
.\mvnw.cmd clean verify
```

To build only the framework and its dependencies:

```shell
bash ./mvnw -pl xs-net -am clean verify
```

The first build downloads Maven dependencies. SDK sources are generated by a Maven plugin; see the [OpenWiki SDK generation guide](openwiki/integrations/sdk-generation.md).

## Run the example locally

Start Redis and PostgreSQL:

```shell
docker compose up -d
```

Then follow the [game server guide](game-server/README.md) to build and start Login, Logic, and Gateway. Example configuration is for local development. Replace JWT secrets, database credentials, and management tokens before deployment.
